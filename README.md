 About

THE FACTORY is a short first-person horror game developed in Unity and C#.

The player explores an abandoned factory connected to a series of disappearances from 1999. The game focuses on exploration, atmosphere, environmental storytelling, interactive objectives, and scripted horror encounters.

Tech Stack

- Unity
- C#
- Universal Render Pipeline (URP)
- Unity Input System
- Unity Audio System
- Unity Video Player

Features

- First-person horror gameplay
- Atmospheric environments with rain, fog and lighting
- Interactive objects and objectives
- Custom forklift/crane gameplay
- Telephone and environmental interactions
- Scripted horror encounters
- Enemy chase system
- Multiple ending routes
- Custom audio and visual effects
Development

Development time: 53 days

Platform: Windows

Estimated playtime: 8–12 minutes

Genre: First-Person Horror

This project was developed as an individual game-development project to learn and implement gameplay programming, level design, lighting, audio, interaction systems and enemy behaviour in Unity.
The playable game is hosted on itch.io.

This repository contains selected project files and scripts to showcase the development and technical implementation of the game.
